# Memorilab
Un modo juego dentro de la web del Memory Lab, con tres niveles que reutilizan los simuladores:

Nivel 1: mantené la CPU útil por encima del 70% ajustando procesos y swap.

Nivel 2: configurá local/global y PFF para que ningún proceso supere cierta tasa de fallos.

Nivel 3: elegí el tamaño de página para minimizar la sobrecarga.
Cada nivel da puntaje y el curso puede competir en un ranking por celular con un QR.

Nivel 4 : Trivia de preguntas Son 8 preguntas, dos por bloque, con cuatro opciones cada una.
